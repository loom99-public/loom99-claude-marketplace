==============================================================================
COMMON ERROR HANDLING PATTERNS
==============================================================================

All hooks now implement:

1. PROJECT DIRECTORY VALIDATION
   - Checks CLAUDE_PROJECT_DIR environment variable
   - Falls back to os.getcwd() if not set
   - Validates directory exists and is writable
   - Returns clear error messages

2. EXECUTION ID VALIDATION
   - Format: YYYYMMDD-HHMMSS (exactly 15 characters)
   - Regex: ^\d{8}-\d{6}$
   - Prevents path traversal (no /, \, or ..)
   - Used in session_end and session_start

3. ERROR LOGGING
   - All errors logged to .agent_planning/.exec/hook_errors.log
   - Format: [timestamp] [hook_name] ERROR: message
   - Includes full stack trace for debugging
   - log_error() function never throws exceptions

4. GRACEFUL EXIT
   - Always exit with status 0 (never block Claude)
   - Silent exit on non-critical errors (empty stdin, wrong tool type)
   - Log errors but continue execution

5. ATOMIC OPERATIONS
   - File locking with timeout (pre_tool_use)
   - Verification after write (pre_tool_use)
   - Cleanup on partial failure (user_prompt_submit)
   - Race condition protection (session_start)
