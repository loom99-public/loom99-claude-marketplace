### P1: Governor Agent + Skills

**P1.1: Create Governor agent**
- Location: `plugins/agent-control-loop/agents/governor.md`
- Pattern: Follow `plugins/do/agents/project-evaluator.md` structure
- Behavioral rules from CONTEXT-PRIME.md:
  1. Work always justified by blocker or DoD item
  2. Drift corrected by editing TARGET.md, not improvisation
  3. Legacy resurrection prevented by BOUNDARY.md enforcement
  4. Each phase eliminates blocker OR produces bounded decision request
  5. Metrics move monotonically or force escalation

**P1.2: Create phase-ritual skill**
- Location: `plugins/agent-control-loop/skills/phase-ritual/SKILL.md`
- Implements the phase ritual procedure:
  1. Artifact restatement (read + summarize TARGET/BOUNDARY/BLOCKERS/METRICS)
  2. Single-blocker selection with justification
  3. Phase plan generation (3-7 steps with verifications)
  4. Stop conditions definition
  5. Phase outcome recording

**P1.3: Create artifact-templates skill**
- Location: `plugins/agent-control-loop/skills/artifact-templates/SKILL.md`
- Templates for 4 live artifacts:
  - TARGET.md (goal + non-goals + target shape + DoD)
  - BOUNDARY.md (boundary law + bridge + forbidden deps + exceptions)
  - BLOCKERS.md (active blockers + escalations)
  - METRICS.md (2-4 metrics with definition/method/current/target/delta)

### P2: Core Commands

**P2.1: Create /loop:init command**
- Location: `plugins/agent-control-loop/commands/init.md`
- Purpose: Bootstrap governance/ directory with artifact templates
- Flow:
  1. Accept goal statement from user
  2. Scan repo for architecture boundaries
  3. Prompt for boundary law and bridge location
  4. Generate artifacts in `governance/live/`
  5. Display initialization summary

**P2.2: Create /loop:phase command**
- Location: `plugins/agent-control-loop/commands/phase.md`
- Purpose: Execute one phase of the control loop
- Flow:
  1. Verify governance/live/ exists
  2. Spawn Governor agent with phase-ritual skill
  3. Execute phase ritual
  4. Display phase summary + next action

**P2.3: Create /loop:status command**
- Location: `plugins/agent-control-loop/commands/status.md`
- Purpose: Quick snapshot of governance state
- Output format:
```
===================================
Control Loop Status
===================================
TARGET: [Goal statement excerpt]
  DoD Progress: 3/7 complete

BLOCKERS: 5 active
  1. [blocker-1] - blocks [DoD-item]
  2. [blocker-2] - blocks [DoD-item]
  3. [blocker-3] - blocks [DoD-item]

METRICS:
  Legacy imports: 47 -> 32 (delta: -15)
  Failing tests: 12 -> 8 (delta: -4)

Recommended: /loop:phase to attack blocker-1
===================================
```
