**Use do-simple if**:

- [ ] Update `plugins/do/commands/it.md`: add routing feedback before Skill tool invocation
- [ ] Feedback format: "🎯 Routing to: [skill-name] skill (detected: [trigger-keywords])"
- [ ] If no clear match: "⚠️ No specific workflow detected, using default. Did you mean: [suggestions]?"
- [ ] Add fallback suggestions based on Levenshtein distance or keyword similarity
- [ ] Test with intentional typos: "/do:it refractory" suggests "refactor" skill
- [ ] Document routing logic in CLAUDE.md for transparency

#### Technical Notes

**Implementation approach**:
1. Before invoking Skill tool, output routing decision
2. Use fuzzy matching on trigger keywords (edit distance ≤ 2)
3. If ambiguous (multiple skills match), present choice to user
4. If no match, explain default behavior and suggest closest matches

**Example output**:
```
User: /do:it refactor auth module
Assistant: 🎯 Routing to: refactor skill (detected: "refactor")
[invokes refactor skill]

User: /do:it refractory auth
Assistant: ⚠️ Did you mean "refactor"? Routing to: refactor skill
[invokes refactor skill]

User: /do:it something unclear
Assistant: ⚠️ No specific workflow detected. Using iterative-workflow skill (default).
Did you mean: tdd, debug, fix, review?
```
