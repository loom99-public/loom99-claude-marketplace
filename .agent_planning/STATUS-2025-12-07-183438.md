### Requirements Analysis

The proposal specifies a **hook-based architecture** with 5 lifecycle hooks:

1. **UserPromptSubmit Hook** - Detect `/do:` commands, generate execution ID, create log directory
2. **PreToolUse Hook (Task matcher)** - Track sequence numbers, inject context
3. **SubagentStop Hook** - Copy transcript to log file
4. **SessionEnd Hook** - Invoke summarizer, archive logs, create EXEC report
5. **SessionStart Hook** - Cleanup leftover files from interrupted sessions

### File Naming Convention Specified

```
.agent_planning/_slash_command_logs_tmp/<timestamp>-<command_summary>/<N>-<subagent_name>-<5_word_summary>.log
```

**NOTE**: This differs from what's implemented in agents! Agents currently use:
```
.agent_planning/.exec/PARTIAL-<execution-id>-<sequence>-<agent>.txt
```
