**Content** (~15 lines per file):
```markdown
## Critical Principle: Runtime Trumps Tests

**ALWAYS ALWAYS ALWAYS**: If runtime fails, tests mean nothing.

Tests are easy to trust because they give green checkmarks. But tests can pass while the software is completely broken. When runtime behavior contradicts test results, trust the runtime.

Process:
1. Run the software (not just tests)
2. Observe actual behavior
3. If runtime works: Tests are accurate OR don't matter
4. If runtime fails: Tests have blind spots, report this explicitly
```
