## Current Log Patterns

### Naming Conventions
1. **Session Logs**: `<session-id>-DEBUG.log` (UUID-based, unique per session)
2. **Hook Logs**: `hook.log` (fixed name, aggregated)
3. **Partial Logs**: `<exec-id>-<seq>-PARTIAL-<agent>.txt` (stored in `partials/` subdirectory)

### Log Content Types
- **Session initialization**: Directory creation, session metadata
- **Execution tracking**: Agent sequence numbers, partial aggregation
- **Debug information**: Timestamps, file paths, error handling
- **Hook aggregation**: "init" and "aggregate" operations

## Problems Identified

### 1. Fragmented Log Locations
- Logs scattered across multiple `.agent_planning/do-command-logs/` directories
- No centralized logging configuration
- Each plugin hardcodes its own log path

### 2. Uncommitted Files
- 27 log files showing in `git status`

- No `.gitignore` entries for log files

### 3. No Central `.agent_logs` Directory
