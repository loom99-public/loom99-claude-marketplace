# Sprint Plan: Centralize Agent Logging Configuration
Timestamp: 2025-12-15-140000
Topic: Agent logging configuration - finding agents/commands writing uncommitted logs
Source STATUS: STATUS-2025-12-15-113000.md

## Executive Summary

Agent logs are currently scattered across multiple `.agent_planning/do-command-logs/` directories, creating 27 uncommitted files in git status. This sprint centralizes all agent logging into a single `.agent_logs/` directory with plugin-specific subdirectories. The implementation requires minimal code changes - just updating hardcoded paths in three plugins and adding appropriate git ignore rules.

**Current Issues:**
- 27 uncommitted log files cluttering git status
- Fragmented log locations across multiple directories
- No centralized logging configuration
- Hardcoded relative paths in plugins

**This Sprint Focus:**
1. Create centralized `.agent_logs/` directory structure
2. Update do-more-now plugin to use new logging location
3. Update dev-loop plugin to use new logging location
4. Add appropriate .gitignore entries

## Implementation Details

### Code Changes Required

#### File 1: `plugins/do-more-now/bin/init.py` (Line 15)
```python
# FROM:
BASE_DIR = Path(".agent_planning/do-command-logs")

# TO:
BASE_DIR = Path(".agent_logs/do-more-now")
```

#### File 2: `plugins/do-more-now/bin/aggregate-exec.py` (Line 27)
```python
# FROM:
BASE_DIR = Path(".agent_planning/do-command-logs")

# TO:
BASE_DIR = Path(".agent_logs/do-more-now")
```

#### File 3: `plugins/dev-loop/bin/hello.py` (Lines 13-14)
```python
# FROM:
with open("/tmp/stop-hook-test.log", "a") as f:
    f.write(stdin_data)

# TO:
import os
from pathlib import Path

log_dir = Path(".agent_logs/dev-loop")
log_dir.mkdir(parents=True, exist_ok=True)
with open(log_dir / "stop-hook.log", "a") as f:
    f.write(f"{datetime.now().isoformat()} {stdin_data}")
```

### Git Configuration

```
hook.log

EXEC-*.md
```

### Migration Strategy

1. **Create new structure first** - ensures no interruption to active logging
2. **Update plugins incrementally** - minimizes risk of breaking existing functionality
3. **Test each plugin after update** - verify new logging locations work
4. **Add gitignore rules last** - ensures existing uncommitted logs are properly ignored

### Testing Approach

1. **Directory creation test**: Verify `.agent_logs/` structure exists
2. **do-more-now test**: Trigger SessionStart hook, verify log appears in new location
3. **do-more-now test**: Trigger Stop hook, verify aggregation works
4. **dev-loop test**: Trigger Stop hook, verify log appears in new location
5. **gitignore test**: Create new log files, verify `git status` doesn't show them
